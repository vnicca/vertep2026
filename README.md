# Вертеп «Ясла з видом на перемогу»

Статична сторінка для гурту (GitHub Pages). Текст — чернетка, правки ще будуть.

## Як викласти на GitHub

1. Зайди на [github.com/new](https://github.com/new).
2. Назва репозиторію, наприклад `vertep-yasla`.
3. Постав галочку **Add a README** або залиш порожнім. **Public** — щоб учасники відкривали без логіну.
4. **Add file → Upload files** і закинь усе з цієї папки:
   - `index.html`
   - `styles.css`
   - `README.md`
5. Commit.
6. **Settings → Pages**: Source = **Deploy from a branch**, Branch = `main`, Folder = `/ (root)` → Save.
7. За хвилину-дві лінк буде:
   `https://ТВІЙ-НІК.github.io/vertep-yasla/`

Кидай цей URL у чат гурту. На телефоні читається, через Ctrl+P можна зробити PDF.

## Якщо вже є репозиторій `username.github.io`

Поклади ці файли в підпапку `vertep/` — тоді адреса: `https://username.github.io/vertep/`.
